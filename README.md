# 线路拉坡

离线铁路纵断面测量与拉坡设计桌面应用。当前为 0.1.16 预览，支持 macOS Apple Silicon、Windows 10/11 x64。

## 使用

1. 可先点击顶部“填写模板”，按模板填写测量数据；填写说明中的转站示例不参与导入。然后导入 `.xlsx`，表头包含特征点、点号、前视读数、后视读数，列顺序不限。
2. 设置测点间隔的轨枕根数，默认为 6 根，即 3.6 米。
3. 在折线图或表格中每次选择两个端点，独立生成一个坡段；下一段重新选两个点，不自动接续。右侧可调整起道量、删除坡段或取消当前选点。
4. 保存 `.railproj` 项目以便继续编辑，或导出带可编辑对比图的 Excel 成果。

全程离线，无账号和网络服务。项目文件可在 Windows 与 Mac 之间交换。采用自动假定高程基准，使最低实测点恰好为10 mm；每行显示前视对应的仪器高，转站新仪器高从下一行起使用；现场点号只作标签，距离由记录顺序决定。修改原始数据后保留控制点及其起道量设置。负值不会自动归零。

滚轮连续横向缩放，可用灵敏度滑块调整缩放速度；鼠标默认箭头，实际拖动时显示抓手；左键拖动左右平移，左键单击选点，右键拖动仍可使用。横轴显示记录序号，纵轴使用全区段统一的非负显示基准和 5/10 倍数刻度；表格和导出统一使用假定高程，高差、坡度和起道量不受影响。测量结果表随整个页面滚动，不再设置独立的固定高度滚动区。表格前四列可编辑，Enter 提交、Esc 取消。撤销／重做可用按钮或 Command/Ctrl+Z、Shift+Command/Ctrl+Z。

## 开发与打包

使用 Node.js 22 或更新版本：

```sh
npm ci
npm test
npm start
npm run build:mac
npm run build:win
```

Mac 输出 DMG；Windows 输出免安装 ZIP。构建依赖需要联网下载，已打包应用无需联网或另装运行环境。Mac 预览包暂未使用开发者证书签名和公证。

`src/core.js` 为不依赖界面的计算模块，便于未来复用。Electron 主进程处理文件对话框和读写，渲染进程不开放 Node.js，所有界面资源本地加载。ExcelJS 读写工作簿，OOXML 散点图引用记录序号及图示高程，与界面共用坐标规则；真实距离只用于坡度计算。导出图表保留当前缩放范围和标注选项，导出全部区段前点击“显示全部”。

详细规则见 [需求说明](需求说明.md)。当前支持带公式导出与自定义半径圆曲线。微信小程序、抛物线及规范推荐半径尚未实现。

特征点名称使用独立标注区，密集时自动分层并扩展高度，长名称换行；引导线连接对应测点，缩放和平移后自动重新布局。

## 本机新版交付

每次生成新版后，将 Mac 应用更新安装到 `/Applications/线路拉坡.app`，不只提供构建目录链接。安装前检查运行中的旧版，避免强制退出或丢失未保存项目；安装后核对版本并启动。Windows 安装包仍单独生成。

控制点可按住橙色圆点左右拖动，拖动中吸附预览目标测点并保留起道量，坡线、起道量及统计实时更新，松开确认；已有控制点不覆盖，Esc取消，撤销/重做可恢复。空白处拖动仍平移。Excel成果默认不启用表头筛选。

开发时可运行 `npm run test:desktop`，在隐藏Electron测试窗口中验证控制点拖动和取消操作，不读取用户项目。

项目格式升级为版本2，保存明确的坡段端点配对及待选端点。打开旧版项目时保留其原有连续设计并转换为显式坡段；新保存的版本2项目需要用v0.1.11及以后版本打开。未设计区段在界面和Excel图中均断开，即使两个坡段端点位于相邻测点也不自动连接。

选中新坡段的第一个端点后，该点显示蓝色实心与外圈，图下固定工具栏切换为选点提示，右侧卡片及表格行同步高亮；共用已有端点也有相同反馈。选完第二点或取消后恢复普通样式。

界面状态提示复用已有固定区域，避免选点、取消等操作触发页面跳动；侧栏内容在自身区域滚动，不反向撑高图表及推动结果表。


### 0.1.14 工作台界面

顶部按输入/保存与输出分组，紧凑统计条让图表更突出；右侧区分已建坡段与端点起道量，点击“定位”放大查看对应坡段，点击“显示全部”恢复。浅灰背景、白色工作区、青蓝主操作统一配色；实测青色、设计橙色、负值红色、待选蓝色保留明确含义。结果表浅蓝列可编辑，页面滚动仍可查看全部记录。

设计参考：[QGIS 面板、工具栏与画布组织](https://docs.qgis.org/3.44/en/docs/user_manual/introduction/qgis_gui.html)、[Ant Design 数据展示规范](https://ant.design/docs/spec/data-display/)。仅参考布局原则，自行实现本地 HTML/CSS，未引入第三方界面框架或在线资源。


### 图文使用手册（0.1.16）

点击顶部“使用手册”打开独立的离线窗口，或直接打开 [使用指南](src/manual/index.html)。涵盖模板填写、转站、间距设置、独立两点拉坡、拖动与起道量、图表、结果编辑和文件保存导出；目录跳转、5张演示截图均可离线使用，点击图片可放大，Esc关闭大图。

手册资源位于`src/manual/`，随Mac和Windows应用打包。截图仅用内置模拟数据，可运行`npm run docs:images`重新生成；`npm run test:manual`验证真实按钮、预加载桥接、独立窗口、图片、目录及项目状态保持。
