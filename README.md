# 线路拉坡

离线铁路纵断面测量与拉坡设计桌面应用。当前为 0.1.0 首版预览，支持 macOS Apple Silicon、Windows 10/11 x64。

## 使用

1. 导入 `.xlsx`，表头包含特征点、点号、前视读数、后视读数，列顺序不限。
2. 设置测点间隔的轨枕根数，默认为 6 根，即 3.6 米。
3. 在折线图或表格勾选控制点，在右侧调整各点起道量。
4. 保存 `.railproj` 项目以便继续编辑，或导出带可编辑对比图的 Excel 成果。

全程离线，无账号和网络服务。项目文件可在 Windows 与 Mac 之间交换。首点相对高程设为 0；现场点号只作标签，距离由记录顺序决定。修改原始数据后保留控制点及其起道量设置。负值不会自动归零。

滚轮横向缩放，右键拖动平移，左键选点。表格前四列可编辑，Enter 提交、Esc 取消。撤销／重做可用按钮或 Command/Ctrl+Z、Shift+Command/Ctrl+Z。

## 开发与打包

使用 Node.js 22 或更新版本：

```sh
npm ci
npm test
npm start
npm run build:mac
npm run build:win
```

Mac 输出 DMG；Windows 输出免安装 ZIP。构建依赖需要联网下载，已打包应用无需联网或另装运行环境。Mac 预览包暂未使用开发者证书签名和公证。

`src/core.js` 为不依赖界面的计算模块，便于未来复用。Electron 主进程处理文件对话框和读写，渲染进程不开放 Node.js，所有界面资源本地加载。ExcelJS 读写工作簿，OOXML 散点图引用真实距离及高程数据，不以点号差计算距离。

详细规则见 [需求说明](需求说明.md)。微信小程序、带公式导出和竖曲线不在本次实现范围内。
