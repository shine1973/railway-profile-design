线路拉坡使用指南

从水准仪原始尺读数出发，选择两个端点连成坡线，查看每个测点的起道量。

第一次使用，按这条顺序操作

填写模板 → 导入 Excel → 设置轨枕根数 → 每段选两个端点 → 调整起道量 → 保存项目 → 导出成果

可先关闭本手册，在空白项目中点击“试用演示数据”练习。手册与项目是两个独立窗口；查看手册不会修改正在编辑的项目。

01 / 准备数据

只需填写四列原始信息

  1. 点击主界面顶部“填写模板”，选择保存位置。
  2. 用 Excel 或 WPS 打开模板，在“测量数据”工作表中按实际测量顺序逐行填写。
  3. 保存为 .xlsx 文件，再回软件导入。模板内“填写说明”的示例不会参与导入。
特征点点号前视读数后视读数填写要点
起点-21200普通测点，后视留空
转站点-11250800原站读 1250；新站复测同一点读 800
0830新站继续测量下一个点
终点1850按实际测量顺序继续填写

上表为填写示例，读数单位均为 mm，不是现场数据。

转站共同点只占一行。把转站后复测该点的读数填在该行“后视读数”里，不另加一行。这样共同点不会被当作新的测点增加距离。
  • 特征点：选填，可写“起点”“道岔尖轨”等。
  • 点号：必填整数，允许 -2、-1、0，也允许现场误标造成的重复或跳号。
  • 前视读数：每个测点必填整毫米数值，例如 1250。
  • 后视读数：只在转站共同点填写；普通点留空，不能用 0 代替空白。

不要在读数里写“mm”、公式或小数。软件按表头识别四列，不要求列的位置固定；原表已有高程等结果列会被忽略并重新计算。一个文件只保留一个符合这四个表头的测量工作表。

02 / 导入

确认记录顺序与测点间距

  1. 点击“导入 Excel”，选择填写好的文件。
  2. 在顶部修改项目名称，并核对测量点数量。
  3. 在右上方“测点间隔”输入每次测量跨过的轨枕根数，提交后查看旁边的米数。
5 根 → 3.0 m6 根 → 3.6 m（默认）12 根 → 7.2 m

轨枕间距固定为 0.6 m，同一项目使用固定根数。距离按记录顺序计算，现场点号只作标识。即使现场点号写重复或漏了一个编号，也不要为此删除实际测点记录。

不需要绝对高程或闭合测量。软件自动设置假定高程基准，使最低实测高程为 10 mm；仪器高自动计算，不需要手动输入。

03 / 拉坡

每一段都重新选择两个端点

  1. 在图上点击第一个测点，或在结果表的“控制”列勾选该点。
  2. 出现蓝色实心点与外圈，图下显示“请选择另一端”，说明第一个点已选中。
  3. 再点击第二个测点，生成本段橙色设计线。新选控制点默认起道量为 0 mm，即按实测高程连线。
  4. 做下一段时，重新选两个端点；软件不会自动继承上一段的终点。

中间有一段不拉坡，怎样选？

例如按记录序号依次选择 1、20、26、42，只会生成 1～20 和 26～42 两段。21～25 保持“未设计”，两段之间不会自动连线。

下一段可以复用上一段终点：仍要先点击该终点，确认它变蓝，再选另一个点。已有端点保留原来的起道量设置。坡段内部不允许重叠，但可以共用一个边界端点。

未连接区间、第一段之前和最后一段之后保留实测数据，设计高程和起道量显示“未设计”。

04 / 调整

调整起道量，或把端点移到相邻测点

在右侧“端点起道量”输入整数，按 Enter 或点击别处提交。坡线、表格和统计随即重新计算。直坡交点目标高程 = 实测高程 + 端点起道量设置。设置竖曲线后，曲线可能不经过交点；最终设计高程与起道量以表格为准。

先延长前坡，再连接后坡

  1. 先选两个测点建立第一段直坡。
  2. 右侧“末端拖动”默认是“保持坡度延长”。按住第一段末端橙点，拖到所需测点序号；端点高度沿原坡度计算，不吸附到实测高程。
  3. 拖动时实时显示延长线和计算结果。松开后端点变蓝，直接再点击后坡终点，即可生成第二段。若继续拖动这个蓝色端点，则保留原起道量，按目标测点的实测高程重新连线，不再按原坡度延长；松开后仍可直接选择后坡终点。
  4. 若暂不接后坡，点击“取消”退出待选状态，已延长的前坡保留。需要竖曲线时，再填写这两段之间的半径。

延长自动生成的起道设置内部可有小数，以精确保留坡度；界面仍显示整毫米，保存和导出不舍入。手动修改起道量仍输入整毫米。延长及接后坡各可单步撤销，拖动中按Esc取消。

原有控制点移动方式

要保留起道量更换测点，把“末端拖动”切换为“保留起道量移动”。起点及已共用的中间端点仍按原来的移动方式处理。

  1. 在图中把鼠标放到橙色空心控制点上，按住左键。
  2. 向前或向后拖动到目标测点，软件吸附到最近测点。拖动过程中，坡线与起道量实时变化。
  3. 松开鼠标完成；该端点保留原来的起道量设置。按 Esc 可取消本次拖动。

共用端点移动时，所有关联坡段一起更新。目标已被其他控制点占用，或移动后造成坡段内部重叠时，不提交该次移动。

负值保留，不自动抬高坡线。红色起道量表示设计高程低于实测高程。请手动调整端点起道量或位置，直到符合自己的设计意图。

右侧“删除”移除对应坡段；端点卡片的“×”移除该控制点及其关联坡段。“清除全部”清除全部坡段和控制点，原始测量数据仍保留。误操作可用“撤销”；一次完整拖动只需撤销一次。

06 / 核查数据

看懂计算结果，直接修正原始记录

表格浅蓝底的特征点、点号、前视、后视四列可编辑。点击单元格，输入后按 Enter 或点击别处提交；按 Esc 取消。无效内容会提示原因，计算继续使用上一次有效值。

结果列含义
仪器高本行前视读数对应的仪器高。转站行仍显示原站仪器高，新站仪器高从下一行起使用。
实测 / 设计高程实测为统一假定基准下的高程；设计由所属坡段连线计算。未设计位置保留实测，设计显示“未设计”。
起道量设计高程 − 实测高程，单位 mm；负值用红色显示，不自动归零。
坡度从本点到下一点的设计高程增量 ÷ 测点间距，单位 ‰。
递增量从本点到下一点的设计高程增量，单位 mm，等于坡度 × 测点间距。

例如坡度为 2.0‰、间距为 3.6 m，则递增量为 7.2 mm。坡度和递增量显示一位小数，其余高程与起道量显示整毫米；内部计算保留精度。

每段末点的坡度、递增量留空；如果该点同时是下一段起点，则显示下一段从该点到下一点的值。没有坡线连接的点间不计算这两项。

07 / 保存成果

项目文件用于继续编辑，Excel 用于交付查看

保存项目 · .railproj

点击“保存项目”，选择文件名与位置。保留原始读数、轨枕根数、控制点起道量、坡段配对与待选端点。

下次点击“打开项目”继续。项目文件可在 Windows 和 Mac 之间交换；不要依靠导出的 Excel 恢复坡段设计。

导出 Excel · .xlsx

点击“导出 Excel”，保存计算结果与可编辑对比图。包含原始记录、仪器高、实测与设计高程、坡度、递增量和起道量，负起道量标红。

成果表保留全部测点，图表采用当前缩放范围和标注选项。要导出全区段图，请先点“显示全部”。

导出 Excel 不等于保存项目。完成调整后建议先保存 .railproj，再导出 .xlsx。顶部默认选择“带公式”，也可改为“仅数值”。修改公式成果的输入后，可重新计算结果。

项目名称旁“未保存”表示当前修改尚未保存。导入另一份 Excel、打开另一个项目或退出软件前，请先保存需要保留的设计。

08 / 竖曲线与公式

自定义半径，平滑连接相邻坡段

  1. 在顶部填写测量日期和测量地点，两项可留空，随项目保存，并在Excel整张成果表的顶行显示。
  2. 分别创建前后两个坡段，例如依次选择序号 1、10、30、45；两段不必共用端点。
  3. 向下滚动右侧面板，找到“竖曲线”。在“坡段 1 → 2”组合处填写半径 R（米），提交后重新计算；清空半径可恢复直坡。

当前实现精确圆曲线几何，表格按每个测点距离计算。图表以测点设计高程连线展示，曲线起终点用小圆点标出，并与其他特征点一起自动避让文字标注。橙色大控制点用于确定两条直坡线，虚线交点由两坡延长计算，设置竖曲线后最终起道量可能与该点设置值不同。

曲线超出相邻坡段、相互重叠或两侧坡度相同时，会提示原因，暂显示直坡并禁止导出。减小半径、调整端点或清空半径后恢复。仅设置半径的前后坡段组合会连接并计算过渡区；未设置的空档保持未设计。

软件显示“可容纳最大半径”和“几何可用值”。最大半径根据坡度差、两侧可用长度及相邻已设置竖曲线计算；几何可用值不乘固定比例，从不超过上限、最多两位有效数字的整米候选值中，选取满足只起不落的最大值。检查前后两坡段及连接区的全部实测点，并考虑相邻已设置曲线；判断使用未取整高程。找不到合适取整半径时，提示手动调整控制点，并列出候选值中最小的最大欠缺量、现场点号及记录序号；这不是自动抬高量。软件不会自动修改坡线或控制点。手动填写半径仍允许产生负值，继续红色标记。点击“采用可用值”才写入半径，仍可手动修改。软件输入上限为 10000000 m；几何上限不足 1 m 时不提供整数可用值，允许手动填写小数。改变坡线会更新可用值，不会自动覆盖已填半径。几何可用值不依赖速度等级，也不代表规范限值；使用者应自行核对线路要求。没有道岔、缓和曲线或桥梁侵限自动校核。

表格在设计高程与坡度之间显示“竖曲线半径（m）”，曲线覆盖的测点显示半径，其余留空。曲线头尾可以位于测点之间，标注精确定位，不新增虚构测量行。

在 Excel 中继续计算

顶部选“带公式”再导出。Excel 第1行为测量日期和地点，第2行为列标题，第3行开始为测点记录；前两行随滚动冻结。测量数据的前四列保持原始输入，后七列为计算结果，其中新增“竖曲线半径（m）”：曲线内显示半径、范围外留空。带公式导出时相应结果由公式计算。参数集中在“输入参数”：B2 为轨枕根数，B6 起为控制点起道量，H6 起为竖曲线半径，均用蓝色底标出。前四列原始读数仍在“测量数据”中修改。参数与公式都可编辑，不设工作表保护。

按“输入参数 → 坡段计算 → 竖曲线参数 → 测点竖曲线 → 测量数据”的顺序查看计算链。“公式分步说明”逐列给出中文含义和公式示例，表头也有中文批注。设计高程引用分步结果，圆曲线的距离、根式、高差拆列计算，不再合为长公式。

例如“输入参数”E7 的 =D7+B7 表示实测加起道设置；可改为 =D7+B7+5，该控制点设计高程将增加 5 mm，并传递到成果与图表。建议先另存一份，再修改一行核对；需向下填充时，仅在同一坡段内操作，带 $ 的引用保持对应坡段行固定。

改读数、间距、起道设置或半径后，Excel/WPS 应自动重算；手动计算模式下请执行重新计算。曲线几何无效时结果显示 #N/A，查看竖曲线参数 P 列。测点增删、端点移动、坡段配对及竖曲线增删请回软件操作后重新导出。

导出时图表坐标与软件一致。改动表格后图表系列随公式更新，但坐标范围沿用导出时设置，超出时需在 Excel/WPS 调整坐标轴。计算过程仍保留完整精度，仅显示值按整毫米或一位小数处理。

新版项目格式为版本 6，可读取版本1至5的旧项目；新版保存后应使用 0.1.20 或更新版本打开。

常见问题

导入提示缺少表头？
核对四个名称：特征点、点号、前视读数、后视读数。检查文件是否为 .xlsx，是否存在多个符合表头的工作表。
导入提示某行读数无效？
按提示中的 Excel 行号修改。点号和前视不能为空；读数用整毫米数字，不填公式、单位文字或小数。
点号重复或跳号，需要补行吗？
不需要。只要实际未漏测，就按真实记录顺序保留每个点。不要按点号排序，或为误标补出不存在的测点。
后视输入 0 和留空一样吗？
不一样。留空表示没有转站；0 是一个有效的后视读数，会参与转站计算。
点了一次却没出现坡线？
蓝色表示第一个端点已选中，还需要点击第二个端点。每一段都要独立选两个点。
修改原始读数后，高程整体变化？
软件会重算转站衔接与统一假定基准，使最低实测点维持 10 mm。控制点起道量设置保留，坡线按新的实测值重新计算。
导出图只显示一部分？
导出图继承当前显示范围。先点“显示全部”再导出；成果表中的测点记录始终完整。
没有网络，手册还能看吗？
可以。软件、手册和截图均随安装包提供，不需要联网。微信小程序、抛物线及规范自动校核尚未包含在当前版本中；当前提供半径几何可用值。
